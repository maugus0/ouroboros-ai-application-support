## Objective

---

## Scope

- [ ] Add function `run_bias_eval(case, dry_run)` in `run_evals.py`:
  - Read `demographic_variants` from the case (if not present → skip)
  - For each variant: merge variant fields into `case["input"]`, call `generate_response()` + `judge_output()`
  - Calculate `bias_gap = max(scores) - min(scores)` between variants
  - If `bias_gap > BIAS_HARD_LIMIT` (env var, default `3.0`) → record `status: "hard_fail"`
  - If `bias_gap > BIAS_THRESHOLD` (env var, default `1.5`) → record `status: "warning"`
  - Otherwise → record `status: "ok"`
- [ ] Add field `bias_report` to `eval_results.json`
- [ ] If any case has `status: "hard_fail"` → `run_evals.py` exit(1)
- [ ] Print clear warning to console for `status: "warning"`
- [ ] `--dry-run` flag still works for bias eval (mock score 7.0 and 7.5 for variants)
