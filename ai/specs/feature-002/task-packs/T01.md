## Objective
Create `scripts/check_pii.py` to scan for PII in fixture files and the `pii-guard` job in CI to run on every PR that changes `tests/llm/fixtures/`.

---

## Scope

- [ ] Create `scripts/check_pii.py` with:
  - CLI arg `--path` (directory or file)
  - Regex patterns: email `@gmail/yahoo/hotmail`, VN phone number `0[3-9]\d{8}`, US phone number, VN CCCD 9/12 digits, US SSN
  - Print: file path + line number + pattern type (redact actual value)
  - Exit 1 if there is a match, exit 0 if clean

- [ ] Add `pii-guard` job to `deploy.yml`
