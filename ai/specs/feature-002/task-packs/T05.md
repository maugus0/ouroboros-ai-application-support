## Objective
Create `scripts/push_eval_history.py` to commit `eval_results.json` to the `eval-history` branch after each successful CI run, creating a long-term audit history that is not deleted after 30 days.

---

## Scope

- [ ] Create `eval-history` branch on GitHub (orphan branch, unrelated to main)
- [ ] Create `scripts/push_eval_history.py`:
  - Clone `eval-history` branch into a temporary directory
  - Copy `eval_results.json` → `history/{GITHUB_SHA}.json`
  - `git add`, `git commit -m "eval: {GITHUB_SHA} score={avg_score}"`, `git push`
  - Support `--dry-run` flag: print the steps that will be taken but do not actually push
  - If `GITHUB_TOKEN` is not present → warn and exit 0 (do not block CI)
- [ ] Update `deploy.yml`: step `Update eval baseline` → then add step `Push eval history`

---

## Acceptance Criteria
- [ ] `python scripts/push_eval_history.py --dry-run` runs successfully and prints clear logs
- [ ] After running for real, the `eval-history` branch has file `history/{commit_sha}.json`
- [ ] Script does not crash when `eval_results.json` does not exist (warn and exit 0)
- [ ] Script does not crash when `GITHUB_TOKEN` is not present (warn and exit 0)

---

## Constraints
- Only use `subprocess`, `shutil`, `os`, `json` (stdlib)
- Do not use PyGithub or any API client
- The `eval-history` branch is orphan — does not share history with `main`
