## Objective
Tạo `scripts/store_eval_baseline.py` để tự động cập nhật GitHub repo variable `EVAL_BASELINE_SCORE` sau mỗi lần eval pass, và thêm README tóm tắt cách sử dụng LLMOps pipeline.

## Scope

### Script `scripts/store_eval_baseline.py`:
- [ ] Đọc `eval_results.json` (output của run_evals.py)
- [ ] Lấy `avg_score` từ JSON
- [ ] Dùng GitHub API (qua `gh` CLI hoặc `GITHUB_TOKEN`) để update repo variable `EVAL_BASELINE_SCORE`
  ```bash
  gh variable set EVAL_BASELINE_SCORE --body "$NEW_SCORE" --repo "$GITHUB_REPOSITORY"
  ```
- [ ] Print rõ: "Baseline updated: {old} → {new}"
- [ ] Nếu `GITHUB_TOKEN` không có → print warning và exit(0) (không fail)
- [ ] Support `--dry-run` flag: print what would be updated mà không thật sự update

### Tích hợp vào `deploy.yml` (update T04 job nếu cần):
- [ ] Sau khi `llm-eval` pass, thêm step gọi `store_eval_baseline.py` với `GITHUB_TOKEN`
  ```yaml
  - name: Update eval baseline
    if: success()
    env:
      GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
    run: python scripts/store_eval_baseline.py
  ```
- [ ] Cần thêm `variables: write` vào permissions của `llm-eval` job

### Documentation `ai/specs/feature-001/README.md`:
- [ ] Tạo `ai/specs/feature-001/README.md` tóm tắt:
  - Mục đích của feature
  - Cách chạy prompt-lint local
  - Cách chạy eval local (dry-run vs real)
  - Cách reset baseline manually (khi intentionally thay đổi prompts)
  - Troubleshooting: llm-eval bị skip, baseline drift, flaky judge
