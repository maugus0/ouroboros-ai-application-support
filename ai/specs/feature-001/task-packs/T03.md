## Objective
Create `scripts/run_evals.py` — script to run LLM eval with golden cases, using GPT-4o-mini as judge, outputting a JSON report and appropriate exit code for CI.

## Scope
- [ ] Create `scripts/__init__.py` if it does not exist
- [ ] Create `scripts/run_evals.py` with logic:
  ```
  1. Load golden cases from tests/llm/fixtures/
  2. Load rubric from tests/llm/fixtures/judge_rubric.json
  3. Load baseline from env var EVAL_BASELINE_SCORE (default: 0.0)
  4. For each golden case:
       a. Build system prompt + user content from case["input"]
       b. Call call_openai() directly (not through LLMPipelineService to avoid DB)
       c. Judge: call GPT-4o-mini with rubric → receive JSON {score, reason}
       d. Retry judge 1 time if JSON parse fails
  5. Compute avg_score = mean(all scores)
  6. Write eval_results.json
  7. If avg_score < float(EVAL_BASELINE_SCORE) - 0.5 → exit(1)
  8. Print summary table to stdout
  ```
- [ ] Create `scripts/run_evals.py` support flag `--dry-run` to run locally without using API (mock judge returns score 7.5)
- [ ] Output format of `eval_results.json`:
  ```json
  {
    "run_at": "ISO timestamp",
    "commit_sha": "...",
    "avg_score": 7.8,
    "baseline_score": 7.5,
    "passed": true,
    "cases": [
      {
        "id": "sop-001",
        "score": 8.0,
        "reason": "...",
        "latency_ms": 2341,
        "operation": "sop_generate"
      }
    ]
  }
  ```

## Acceptance Criteria

- [ ] exit(1) when avg_score < baseline - 0.5, with a clear reason message
- [ ] `eval_results.json` valid JSON with correct schema
- [ ] Judge retries 1 time when LLM returns invalid JSON
- [ ] `--dry-run` flag mocks all API calls, incurs no cost
- [ ] All lint/typecheck pass for `scripts/run_evals.py`
