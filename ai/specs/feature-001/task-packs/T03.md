## Objective
Tạo `scripts/run_evals.py` — script chạy LLM eval với golden cases, dùng GPT-4o-mini làm judge, output JSON report và exit code phù hợp cho CI.

## Scope
- [ ] Tạo `scripts/__init__.py` nếu chưa có
- [ ] Tạo `scripts/run_evals.py` với logic:
  ```
  1. Load golden cases từ tests/llm/fixtures/
  2. Load rubric từ tests/llm/fixtures/judge_rubric.json
  3. Load baseline từ env var EVAL_BASELINE_SCORE (default: 0.0)
  4. For each golden case:
       a. Build system prompt + user content từ case["input"]
       b. Call call_openai() trực tiếp (không qua LLMPipelineService để tránh DB)
       c. Judge: gọi GPT-4o-mini với rubric → nhận JSON {score, reason}
       d. Retry judge 1 lần nếu JSON parse fail
  5. Compute avg_score = mean(all scores)
  6. Write eval_results.json
  7. If avg_score < float(EVAL_BASELINE_SCORE) - 0.5 → exit(1)
  8. Print summary table to stdout
  ```
- [ ] Tạo `scripts/run_evals.py` support flag `--dry-run` để chạy local không tốn API (mock judge trả về score 7.5)
- [ ] Output format của `eval_results.json`:
  ```json
  {
    "run_at": "ISO timestamp",
    "commit_sha": "...",
    "avg_score": 7.8,
    "baseline_score": 7.5,
    "passed": true,
    "cases": [
      {
        "id": "sop-001",
        "score": 8.0,
        "reason": "...",
        "latency_ms": 2341,
        "operation": "sop_generate"
      }
    ]
  }
  ```
