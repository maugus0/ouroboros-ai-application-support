## Scope

### Job 1: `prompt-lint` (add to Stage 2, parallel with `type-check`)
- [ ] Add job `prompt-lint` to Stage 2:
  ```yaml
  prompt-lint:
    name: Prompt Lint & Token Validation
    runs-on: ubuntu-latest
    needs: [format-check, lint-check, unit-tests]
    steps:
      - checkout
      - setup-python (use the same PYTHON_VERSION, cache pip)
      - install dev deps
      - run: pytest tests/llm/test_prompt_lint.py -v --tb=short
        env:
          ALLOW_DB_FAILURE: "true"
          USE_MOCK_DATA: "true"
  ```

### Job 2: `prompt-diff-alert` (add to Stage 2, PR only)
- [ ] Add job `prompt-diff-alert`:
  ```yaml
  prompt-diff-alert:
    name: Prompt Change Detector
    runs-on: ubuntu-latest
    if: github.event_name == 'pull_request'
    needs: [format-check, lint-check, unit-tests]
    permissions:
      contents: read
      pull-requests: write
    steps:
      - checkout (fetch-depth: 0 to get git history)
      - detect changed prompt files:
          git diff origin/${{ github.base_ref }}...HEAD --name-only
          | grep -E "(app/llm/|tests/llm/fixtures/)" > changed_prompts.txt || true
      - if changed_prompts.txt is not empty:
          gh pr comment with list files + warning message
          echo to $GITHUB_STEP_SUMMARY
  ```

### Job 3: `llm-eval` (add after Stage 3, push to main only)
- [ ] Add job `llm-eval`:
  ```yaml
  llm-eval:
    name: LLM Output Quality Eval
    if: github.event_name == 'push' && github.ref == 'refs/heads/main' && env.OPENAI_API_KEY != ''
    runs-on: ubuntu-latest
    needs: [docker-build]
    env:
      OPENAI_API_KEY: ${{ secrets.OPENAI_API_KEY }}
      EVAL_BASELINE_SCORE: ${{ vars.EVAL_BASELINE_SCORE || '0.0' }}
      ALLOW_DB_FAILURE: "true"
    steps:
      - checkout
      - setup-python
      - install requirements.txt (not dev)
      - run: python scripts/run_evals.py
      - upload-artifact: eval_results.json (retention 30 days)
  ```
