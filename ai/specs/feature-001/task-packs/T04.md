## Objective
Thêm 3 jobs mới vào `.github/workflows/deploy.yml`: `prompt-lint`, `prompt-diff-alert`, `llm-eval` — đúng vị trí trong dependency graph, không phá vỡ jobs hiện tại.

## Scope

### Job 1: `prompt-lint` (thêm vào Stage 2, song song với `type-check`)
- [ ] Thêm job `prompt-lint` vào Stage 2:
  ```yaml
  prompt-lint:
    name: Prompt Lint & Token Validation
    runs-on: ubuntu-latest
    needs: [format-check, lint-check, unit-tests]
    steps:
      - checkout
      - setup-python (dùng cùng PYTHON_VERSION, cache pip)
      - install dev deps
      - run: pytest tests/llm/test_prompt_lint.py -v --tb=short
        env:
          ALLOW_DB_FAILURE: "true"
          USE_MOCK_DATA: "true"
  ```

### Job 2: `prompt-diff-alert` (thêm vào Stage 2, PR only)
- [ ] Thêm job `prompt-diff-alert`:
  ```yaml
  prompt-diff-alert:
    name: Prompt Change Detector
    runs-on: ubuntu-latest
    if: github.event_name == 'pull_request'
    needs: [format-check, lint-check, unit-tests]
    permissions:
      contents: read
      pull-requests: write
    steps:
      - checkout (fetch-depth: 0 để có git history)
      - detect changed prompt files:
          git diff origin/${{ github.base_ref }}...HEAD --name-only
          | grep -E "(app/llm/|tests/llm/fixtures/)" > changed_prompts.txt || true
      - if changed_prompts.txt không empty:
          gh pr comment với list files + warning message
          echo to $GITHUB_STEP_SUMMARY
  ```

### Job 3: `llm-eval` (thêm vào sau Stage 3, push to main only)
- [ ] Thêm job `llm-eval`:
  ```yaml
  llm-eval:
    name: LLM Output Quality Eval
    if: github.event_name == 'push' && github.ref == 'refs/heads/main' && env.OPENAI_API_KEY != ''
    runs-on: ubuntu-latest
    needs: [docker-build]
    env:
      OPENAI_API_KEY: ${{ secrets.OPENAI_API_KEY }}
      EVAL_BASELINE_SCORE: ${{ vars.EVAL_BASELINE_SCORE || '0.0' }}
      ALLOW_DB_FAILURE: "true"
    steps:
      - checkout
      - setup-python
      - install requirements.txt (không phải dev)
      - run: python scripts/run_evals.py
      - upload-artifact: eval_results.json (retention 30 days)
  ```

## Constraints
- Dùng đúng action versions như đã có trong file: `actions/checkout@v6`, `actions/setup-python@v6`, `actions/upload-artifact@v6`
- Không thay đổi `concurrency` group hay `permissions` ở top level
- `prompt-lint` và `prompt-diff-alert` KHÔNG được block `docker-build` nếu chúng fail (optional quality gate, không bắt buộc trên PR)
  → Thêm `prompt-lint` vào `needs` của `docker-build` CHỈ nếu muốn enforce; discussion cần human decision
