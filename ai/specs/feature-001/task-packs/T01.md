## Objective
Tạo `tests/llm/test_prompt_lint.py` kiểm tra tất cả prompt files hiện có — **không cần API key**, chạy được local và trong CI.

## Scope
- [ ] Tạo `tests/llm/__init__.py` (empty)
- [ ] Tạo `tests/llm/conftest.py` với:
  - `mock_sop_context` fixture — dict đủ các key để inject vào SOP prompts
  - `mock_cover_letter_context` fixture — dict đủ các key cho cover letter
  - `all_prompt_files` fixture — list tất cả file `.json` trong `prompts/` directory
- [ ] Tạo `tests/llm/test_prompt_lint.py` với các test cases:
  - `test_all_prompt_json_files_are_valid_json` — load từng file, assert không throw
  - `test_sop_outline_prompt_renders_without_error` — gọi `get_sop_outline_prompt(context=mock_sop_context)`
  - `test_sop_expansion_prompt_renders_without_error`
  - `test_sop_quality_review_prompt_renders_without_error`
  - `test_cover_letter_prompt_renders_without_error`
  - `test_prompt_token_count_within_limit` — dùng `tiktoken` estimate, assert < 80% model limit
  - `test_no_unfilled_placeholder_in_rendered_prompt` — check không còn `{{` hay `}}` sau render
- [ ] Thêm `tiktoken>=0.7` vào `requirements-dev.txt`
- [ ] Verify: `pytest tests/llm/test_prompt_lint.py -v` chạy pass không cần env vars
